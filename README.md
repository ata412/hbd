# Happy Birthday, มะหมี่ ♡

เว็บวันเกิดแบบ scroll story สร้างด้วย React, Vite และ GSAP ScrollTrigger

## เปิดในเครื่อง

```bash
npm install
npm run dev
```

## Deploy บน Vercel

Import repository เข้า Vercel ได้โดยตรง ระบบจะตรวจพบ Vite และใช้คำสั่ง `npm run build` อัตโนมัติ โดย output directory คือ `dist`
